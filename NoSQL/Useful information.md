# Генератори наборів даних (Data Set Generators)

Огляд корисних сервісів для створення та тестування баз даних, API та аналітичних моделей.

### 1. [MongoDB Atlas Sample Data](https://www.mongodb.com/docs/atlas/sample-data/)
* **Опис**: Колекція готових наборів даних, що надається безкоштовно для користувачів MongoDB Atlas.
* **Призначення**: Швидке тестування функцій Atlas, навчання роботі з NoSQL та побудова прототипів.
* **Особливості**: Містить реальні дані про нерухомість (Airbnb), фільми, погоду та транзакції.

### 2. [GenerateData.com](https://generatedata.com/)
* **Опис**: Інструмент з відкритим кодом для генерації великих обсягів структурованих даних.
* **Призначення**: Створення кастомних таблиць для SQL, JSON або CSV файлів.
* **Особливості**: Дозволяє точно налаштувати типи полів (імена, країни, дати) та підтримує експорт у безліч форматів.

### 3. [Mockaroo](https://www.mockaroo.com/)
* **Опис**: Один із найпотужніших онлайн-сервісів для створення реалістичних тестових даних.
* **Призначення**: Створення макетів API, тестування продуктивності та наповнення БД.
* **Особливості**: Підтримує понад 140 типів даних, логічні формули для зв'язків між полями та можливість автоматизації через API.
